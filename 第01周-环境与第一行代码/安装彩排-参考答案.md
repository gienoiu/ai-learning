# 安装彩排 · 参考答案

> 先自己在纸上写一遍，再对照。抄一遍不如写错一遍记得牢。
> 你电脑的实际情况：Python 在 `D:\python`，Git 在 `D:\Git`，VSCode 在 `D:\Microsoft VS Code`。

## 一、Python

1. 打开 <https://www.python.org/downloads/>，选 Windows 64-bit 安装包（3.12 及以上都行）
2. 双击安装，**第一屏一定要勾上 `Add python.exe to PATH`**（不勾，命令行就找不到 python）
3. 选 `Customize installation`，把安装路径改到非系统盘，比如 `D:\python`（省 C 盘空间，你已经是这么做的）
4. `Install`，装完**重新打开**终端
5. 验证：

```powershell
python --version
pip --version
```

## 二、VSCode

1. 打开 <https://code.visualstudio.com/>，下载 Windows x64 安装包，一路默认
2. 打开后进「扩展」（左侧方块图标），搜 `Python`，装 **Microsoft 官方**那个
3. 验证：`code --version`（或直接打开 VSCode 看版本）

## 三、Git

1. 打开 <https://git-scm.com/download/win>，下载 64-bit 安装包
2. 一路 `Next`（默认选项都合理，别乱改）
3. 验证：`git --version`
4. 身份配置（**第 4 周注册 GitHub 后再做**）：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## 四、四条验证命令（装完必跑）

```powershell
python --version
pip --version
git --version
code --version
```

## 五、常见坑（提前知道，少卡 2 小时）

| 现象 | 原因 | 解决 |
|---|---|---|
| `python` 不是内部或外部命令 | 装的时候没勾 PATH | 重装并勾 `Add python.exe to PATH` |
| 装了多个 Python，版本不对 | 默认那个不是想要的 | 用 `py -3.12 --version` 指定版本 |
| 刚装完命令还是找不到 | 旧终端没刷新环境变量 | 关掉终端重新开一个 |
| `pip` 能装但 `import` 失败 | 装到了另一个 Python 里 | 用 `python -m pip install 包名`，保证「用哪个 python 就装到哪」 |
| 中文乱码 | 终端编码问题 | 先不管，第 2 周统一处理 |

## 六、真正的「重装后还能再装一次」

不是背步骤，而是：**给你一台新电脑，你能不看教程把这三样装好并验证。**
今天写完这张纸，就算通过第一层；等哪天你真要重装系统，照着它做一次，才算彻底掌握。
