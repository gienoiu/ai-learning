## 零基础补丁：终端是什么？「4 条版本命令」怎么跑？

> 第一次碰命令行的人看这段就够了，3 分钟。

**终端** = 一个用打字代替点鼠标的窗口。
**命令** = 一句对电脑说的话。
**「跑命令」** = 敲一句话 → 按回车 → 看电脑怎么回答。

### 1. 先把它打开

VSCode 顶部菜单：`终端 → 新建终端`。
下方弹出一块深色区域，光标前有一行字，长这样：

```text
PS C:\Users\伊鑫\Documents\...>
```

那个 `>` 是电脑在说「我准备好了，你说吧」。**它不是你要打的内容。**

### 2. 一条一条敲（每条按一次回车）

| 敲这个 | 它在问电脑 | 你这台电脑会回答 |
|---|---|---|
| `python --version` | Python 装好了吗 | `Python 3.14.8` |
| `pip --version` | pip（Python 的应用商店）呢 | `pip 26.2.1 from D:\python\Lib\site-packages\pip (python 3.14)` |
| `git --version` | Git 呢 | `git version 2.56.0.windows.2` |
| `code --version` | VSCode 呢 | `1.141.2`，后面再跟两行 |

> `--version` 是**两个英文减号**，别打成中文「——」，中间也别加空格。

### 3. 两种结果

- 四条都返回版本号 → **环境验收通过**，截图存档
- 出现「不是内部或外部命令」「无法将……项识别为……」→ 别自己修，截图发我

### 4. 三个小技巧

- 命令可以复制，在终端里按 `Ctrl + V`（或鼠标右键）粘贴
- 必须按**回车**才会执行，只敲不回车等于没说话
- 终端开头路径和上面不一样没关系，在哪个目录都行

### 5. 以后要新建文件怎么办（比如写练习）

**方法一（推荐）**：左侧「资源管理器」里，在文件夹名上**右键** → `新建文件` → 输入 `练习.py` → 回车。

**方法二**：按 `Ctrl + N` 新建空白文件 → 敲代码 → 按 `Ctrl + S` 保存 → 弹窗里选到 `第01周-环境与第一行代码` 这个文件夹 → 文件名填 `练习.py` → 保存。

**两个坑**：

- 文件名**必须带 `.py`**，否则 VSCode 不知道这是 Python 文件（字不会变彩色，运行也会出错）
- 标签页名字旁边出现**一个圆点** = 还没保存，记得按 `Ctrl + S`

**1. 打开 VSCode**（开始菜单搜 `Visual Studio Code`）。你的界面应该是中文的（已装中文语言包）。

**2. 打开文件夹**：菜单 `文件 → 打开文件夹`，选到
`C:\Users\伊鑫\Documents\deepseek-harness\default-workspace\ai-learning\第01周-环境与第一行代码`

**3. 补装 Python 扩展**：点左侧「扩展」图标（四个小方块），搜 `Python`，装 **Microsoft 官方**那个（发行商写着 Microsoft）。装完按提示重启 VSCode。

> 为什么要装：VSCode 本身只是编辑器，装上 Python 扩展它才认识 `.py` 文件，能自动补全、定位错误。

**4. 打开终端**：菜单 `终端 → 新建终端`（快捷键 `Ctrl + 反引号`，反引号是 Esc 下面那个键）。不明白终端是什么，先看上面「零基础补丁」。

**5. 在终端里逐条敲下面 4 行**，每敲一行按一次回车，把输出和预期对照：

```powershell
python --version
pip --version
git --version
code --version
```

| 命令 | 预期输出（大致） | 它在问什么 |
|---|---|---|
| `python --version` | `Python 3.14.8` | Python 装没装、能不能从命令行叫出来 |
| `pip --version` | `pip 26.2.1 ... (python 3.14)` | pip 是 Python 的「应用商店」 |
| `git --version` | `git version 2.56.0...` | Git 是代码的「时光机」 |
| `code --version` | `1.141.2` 等三行 | VSCode 的命令行入口 |

> 如果哪条提示「不是内部或外部命令」，说明 PATH 没配好——**别自己折腾**，截图发我。

**6. 截图**：按 `Win + Shift + S` 框选整个终端窗口 → 存到 `交付物/` 文件夹，命名 `01-环境验收.png`。

## 任务 2｜跑出第一个程序（25 分钟）

**1.** 在 VSCode 左侧文件列表里点开 `hello.py`（你后来自己新建/改名成了 `lianxi.py`，点你自己的那个就行）。

**2.** **照着敲一遍**（不要复制粘贴），十来行，每行什么意思看文件里的注释。

> 为什么手敲：复制粘贴是「借来的代码」，手敲才会在脑子里留下路径。下周你要自己写 5 个小程序，现在偷的懒都要还。

**3.** 在终端运行它（**文件名换成你自己的**，你现在是 `lianxi.py`）：

```powershell
python hello.py
```

看到 `你好，世界！` 就通过了。

> 如果输出是乱码（一坨问号 / 方块），在终端先敲 `chcp 65001` 回车，再运行一次。
> 这是 Windows 中文编码的老毛病，不是你写错了。

**4.** 改一改，再跑一次（这几个改动是故意让你看见「代码 = 可以随便改的东西」）：

- 把 `name = "伊鑫"` 改成你自己的昵称
- 加一行 `print("今晚我要学", 1, "小时")`
- 再运行，看输出变了没有

**5.** **故意弄坏它**（重要，第一次认识报错）：删掉一个英文引号 `"`，再运行。你会看到一段红字 `SyntaxError`。
**把这段报错原文抄进今天的日志**——以后你每天都会见到它。

**6.** 修好，截图 `02-第一个程序.png`。
