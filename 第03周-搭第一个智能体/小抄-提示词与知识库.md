# 智能体小抄：提示词、知识库、三个词

> 这周不用写代码。你要做的是一个「会按你给的资料回答问题」的机器人。

---

## 一、提示词（人设与回复逻辑）

提示词 = 你写给 AI 的「工作说明书」。写得好不好，直接决定它像不像样。

### 四要素

| 要素 | 回答什么 | 例子 |
|---|---|---|
| **角色** | 你是谁、服务谁 | 你是「XX学院教务小助手」，服务本院大一学生 |
| **任务** | 你要解决哪些问题 | 回答选课、考试、成绩、学籍、补考问题 |
| **知识** | 依据什么回答 | 优先用知识库里的教务文件；没有的就说不知道 |
| **约束** | 什么不能做、多长、什么语气 | 不编造、不聊别的、150 字内、先结论后步骤 |

再加**示例**（2~3 组「用户问 → 你答」），效果立刻上一个台阶。

### 五条实操经验

1. **用「你」不用「它」**：直接对 AI 说话，不要写"这个助手应该……"
2. **给否定清单**：明确写"不要做什么"，比只说"要做什么"有效
3. **要格式就给格式**：想要分点回答，就写"用 1. 2. 3. 分点"
4. **示例比形容词管用**：写"回答要简洁"没用，给一个简洁的例子才有用
5. **一轮改一处**：一次只改一个地方，才知道是哪句起了作用

## 二、三个词（期末可能考）

### Token

模型处理文字的**最小单位**。中文大约 1 个字 ≈ 1~2 个 token，英文一个词 ≈ 1~2 个 token。

- 用处：计费、限长。你看到「最多输入 8000 token」就是这么算的。
- 直觉：token ≈ 字的零头，不是一个字一个。

### 上下文窗口

模型一次能"看到"的**最大 token 数**，包括：系统提示词 + 历史对话 + 你贴的资料。

- 超出窗口的旧内容会被"忘掉"（截断或压缩）
- 所以对话太长时，它可能忘了开头说过的要求——不是它笨，是窗口满了

### RAG（检索增强生成）

**先从知识库检索相关片段，再把片段塞进上下文，让模型基于片段回答。**

- 解决的问题：模型没读过你们学校的教务文件，硬答就会瞎编
- 大白话：**开卷考试**——先翻书找到那一段，再照着答
- 你上传资料建知识库，就是给智能体配了一本"能自动翻的书"

## 三、知识库

- 本质：把你上传的文档切成小段（分段），存进索引
- 提问时：先按相似度找最相关的几段 → 交给模型 → 模型基于这几段回答
- 资料质量决定回答质量：**过时的通知 = 过时的答案**
- 上传格式：txt / pdf / docx / 网页链接都行

---

## 四、工作流（进阶，可以先不碰）

工作流 = 把多个步骤串起来，比如：先判断问题类型 → 再查知识库 → 再决定要不要转人工。

第 1 版智能体用不上。等你能把「提示词 + 知识库」玩明白了，再看工作流。

---

## 五、扣子操作路径（中国版 coze.cn）

1. 登录 → 左上角「工作空间」
2. `+ 创建智能体` → 填名字「教务小助手」→ 确认
3. 左侧「人设与回复逻辑」→ 粘贴提示词
4. 右侧调试窗口 → 直接对话测试
5. 左侧「知识库」→ 创建知识库 → 上传文档 → 等分段完成 → 关联到智能体
6. 右上角「发布」→ 选渠道（豆包 / 飞书 / API / 分享链接）
7. 复制分享链接，发给同学

## 六、回答不好时怎么改

| 现象 | 先改哪里 |
|---|---|
| 答得太长、像论文 | 约束里加「150 字内，先结论后步骤」 |
| 答非所问 | 任务写具体：「只回答选课/考试/成绩，其他礼貌拒绝」 |
| 瞎编学校规定 | 加「不确定就说不知道，建议问辅导员」；同时检查知识库有没有对应资料 |
| 语气太机械 | 加一个「示例」，用你想要的语气写一组问答 |
| 忘了前面说过的要求 | 对话太长，开新对话；或把关键要求再写一遍 |
| 回答跟资料对不上 | 知识库分段可能切碎了，换个文档格式或补一份更清楚的资料 |
