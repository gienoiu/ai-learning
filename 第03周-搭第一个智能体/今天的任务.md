# 第 3 周 · 搭第一个智能体（教务问答机器人）

**清单原文**：搭第一个智能体：提示词、知识库、工作流；Token、上下文窗口、RAG 三个词
**本周交付物**：一个**真人真的会用**的智能体（教务问答机器人）

> 这周你跳过了一次，现在补上。**不用写代码**，但要求「真人真的会用」——做完要发给至少 2 个同学试用。
> 验收不看你做得多花哨，看两件事：**答得准不准**、**同学愿不愿意再用一次**。

---

## 第 1 次（周六，约 2 小时）：先让它能聊天

- [ ] **1. 注册 / 登录扣子**（见文末「准备工作」）
- [ ] **2. 创建智能体**，名字就叫「教务小助手」
- [ ] **3. 写人设与回复逻辑（提示词）**：拿 `教务问答-提示词模板.md` 改
- [ ] **4. 在右侧调试窗口问 3 个问题**，看它答得怎么样
- [ ] **5. 改提示词，至少改 2 轮**，让回答更像人话、更像本校规定

**这次目标**：先不接知识库，只靠提示词，它已经能像样地回答常见教务问题。

## 第 2 次（另约，约 1.5 小时）：喂资料 + 发布

- [ ] **1. 准备教务资料**（见「资料清单」）
- [ ] **2. 建知识库** → 上传资料 → 等它自动分段
- [ ] **3. 把知识库关联到智能体**
- [ ] **4. 对照资料再问一遍**，看回答是不是更准、更具体
- [ ] **5. 发布**：生成分享链接（或发布到豆包 / 飞书）
- [ ] **6. 发给 2 个同学**，各问 1 个真实问题，记录反馈

---

## 交付物与验收

1. **智能体分享链接**（能直接在浏览器打开）
2. **3 个测试问题 + 它的回答截图**：1 个答得好、1 个答得不好都行——**记录不好才有改进空间**
3. **2 个同学的使用反馈**（各一句话）
4. 能用大白话讲清：**Token、上下文窗口、RAG** 这三个词

---

## 准备工作

### 账号

打开 <https://www.coze.cn>，用手机号或抖音登录（免费）。

> 如果扣子打不开或注册不了：换同类平台（**腾讯元器 / 文心智能体 / Dify**），清单里写了「同类型应用代替」，不影响交付物。

### 资料（第 2 次之前准备）

学校教务相关的**公开**资料，任选 2~3 份：

- 教务处官网的「常见问题」页面（可以复制文字，或截图后转文字）
- 学生手册里关于选课、考试、成绩、学籍的章节
- 补考 / 缓考 / 重修的通知

> ⚠️ **不要**放个人隐私：成绩单、身份证号、手机号。
> 知识库只放「公开的、谁问都能答」的内容。

### 3 个问题（先想好）

同学真的会问的那种，比如：

- 补考怎么报名？什么时候截止？
- 绩点怎么算？挂科会不会影响毕业？
- 选课什么时候开放？抢不到怎么办？
