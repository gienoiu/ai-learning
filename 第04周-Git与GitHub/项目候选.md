> **重要**：这周清单的原话是「GitHub **怎么找项目**、怎么读 README」。所以先**自己找 15 分钟**，把找到的链接发我帮你把关；实在找不到合适的，再用下面这 3 个兜底。
>
> 目标：clone 下来 → 按 README 跑出结果 → 改一处 → 再跑。
> 跑不起来就换下一个，这在开源世界很正常。

## 候选 1：tomato-clock（番茄钟，128 行，纯 Python）

- 地址：<https://github.com/coolcode/tomato-clock>
- 依赖：**无**（只用 Python 自带的库）
- 难度：★☆☆
- 为什么推荐：代码短、一看就懂；跑起来是个倒计时，有"哇它动了"的感觉；正好也是番茄工作法工具，你可以真的用它学习。

```powershell
git clone https://github.com/coolcode/tomato-clock.git
cd tomato-clock
dir
```

先看 README（用 VSCode 打开 `README.md`），再跑：

```powershell
python tomato.py -h
python tomato.py -t 1      # 1 分钟的番茄钟，测试用
```

**改造任务**：找到 `WORK_MINUTES = 25` 这一行，改成 1，保存，再跑 `python tomato.py -t`，看看是不是 1 分钟就到了。
（改完不用提交，这是别人的仓库，你只是本地玩。）

## 怎么挑项目（以后自己找时用）

1. 在 GitHub 搜索框搜关键词 + `language:python`，例如 `game language:python`
2. 按 **Most stars** 排序
3. 先看 README 有没有说清楚「怎么装、怎么跑」
4. 看最后更新时间（超过 1 年没更新，谨慎）
5. 依赖越少越好（第一次 clone 别碰要装一堆东西的）

## 跑不起来怎么办

按顺序查：

1. 有没有按 README 的「安装」步骤做？
2. Python 版本对不对（README 里可能会写 `requires Python 3.9+`）
3. 缺依赖？`pip install 报错里提到的包`
4. 文件路径不对？确认你在项目文件夹里（`dir` 能看到 README 和代码）
5. 把 **报错全文 + 你敲的命令** 发我

## 选项目前的 30 秒体检（这次踩的坑）

在点 clone 之前，先看项目的依赖文件，再看 README 里的 Python 版本要求：

- `requirements.txt` / `pyproject.toml` / `setup.py` 里列了哪些包？
- 有没有 PyQt5、pyaudio、cocos2d 这种「Windows + 新 Python 上很难装」的？
- README 有没有写支持的 Python 版本？

**这次的教训**：`CharlesPikachu/Games` 的 `requirements.txt` 是

```text
cocos2d
pyaudio
pyglet
pygame
PyQt5
```

五个重依赖，其中 PyQt5、pyaudio 在 Python 3.14 上基本装不上，pygame 官方也还没出 3.14 的安装包。所以这个项目**第一次 clone 别碰**——不是它不好，是环境不匹配。

> 以后看到依赖超过 3 个、或者有 PyQt5 / pyaudio / cocos2d 这类名字，先停下来想想。
