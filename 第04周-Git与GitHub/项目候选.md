# 项目候选（第 4 周 clone 练习）

> 目标：clone 下来 → 按 README 跑出结果 → 改一处 → 再跑。
> **选一个就行，推荐第 1 个。** 跑不起来就换下一个，这在开源世界很正常。

---

## 候选 1：tomato-clock（番茄钟，128 行，纯 Python）

- 地址：<https://github.com/coolcode/tomato-clock>
- 依赖：**无**（只用 Python 自带的库）
- 难度：★☆☆
- 为什么推荐：代码短、一看就懂；跑起来是个倒计时，有"哇它动了"的感觉；正好也是番茄工作法工具，你可以真的用它学习。

```powershell
git clone https://github.com/coolcode/tomato-clock.git
cd tomato-clock
dir
```

先看 README（用 VSCode 打开 `README.md`），再跑：

```powershell
python tomato.py -h
python tomato.py -t 1      # 1 分钟的番茄钟，测试用
```

**改造任务**：找到 `WORK_MINUTES = 25` 这一行，改成 1，保存，再跑 `python tomato.py -t`，看看是不是 1 分钟就到了。
（改完不用提交，这是别人的仓库，你只是本地玩。）

## 候选 2：python-beginner-projects（270+ 新手项目合集）

- 地址：<https://github.com/Mrinank-Bhowmick/python-beginner-projects>
- 依赖：看具体项目（每个文件夹有自己的 README）
- 难度：★★☆
- 适合：想练"在一堆项目里挑一个"的能力。仓库大，clone 会比较慢，建议加 `--depth 1`。

```powershell
git clone --depth 1 https://github.com/Mrinank-Bhowmick/python-beginner-projects.git
cd python-beginner-projects
dir
```

挑一个**只用标准库**的项目（比如命令行小游戏、计算器），进去看它的 README 再跑。

## 候选 3：Games（纯 Python 小游戏合集）

- 地址：<https://github.com/CharlesPikachu/Games>
- 依赖：`pygame`（要 `pip install pygame`）
- 难度：★★★
- 适合：想看到图形窗口、有游戏画面的。仓库大，clone 慢。

```powershell
git clone --depth 1 https://github.com/CharlesPikachu/Games.git
cd Games
pip install pygame
dir
```

按 README 找一个小游戏（比如 2048、贪吃蛇），运行它的入口文件。

## 怎么挑项目（以后自己找时用）

1. 在 GitHub 搜索框搜关键词 + `language:python`，例如 `game language:python`
2. 按 **Most stars** 排序
3. 先看 README 有没有说清楚「怎么装、怎么跑」
4. 看最后更新时间（超过 1 年没更新，谨慎）
5. 依赖越少越好（第一次 clone 别碰要装一堆东西的）

## 跑不起来怎么办

按顺序查：

1. 有没有按 README 的「安装」步骤做？
2. Python 版本对不对（README 里可能会写 `requires Python 3.9+`）
3. 缺依赖？`pip install 报错里提到的包`
4. 文件路径不对？确认你在项目文件夹里（`dir` 能看到 README 和代码）
5. 把 **报错全文 + 你敲的命令** 发我
