### 2. 配置身份

Git 每次提交都会记录「谁改的」，所以先告诉它你是谁：

```powershell
git config --global user.name "你的GitHub用户名"
git config --global user.email "你注册GitHub的邮箱"
git config --global core.quotepath false
git config --global --list
```

最后一条能列出这三行，就对了。

> `core.quotepath false` 是让 Git 正常显示中文文件名（不然会显示成一串 `\346\226\207...`）。

### 3. 初始化仓库

**先进入 ai-learning 文件夹**（这是整个学期的根目录）：

```powershell
cd "C:\Users\伊鑫\Documents\deepseek-harness\default-workspace\ai-learning"
```

```powershell
git init
```

看到 `Initialized empty Git repository in ...` 就成功了。再敲：

```powershell
git status
```

会列出所有文件（红色 = 还没被 Git 管）。**现在文件都还是"未跟踪"状态。**

### 4. 建 .gitignore

在 ai-learning 根目录新建文件 `.gitignore`（文件名开头有个点，没有扩展名），内容：

```text
__pycache__/
*.pyc
.venv/
.vscode/
测试残留*/
```

> `.gitignore` = 告诉 Git「这些东西别管」。比如虚拟环境、缓存、编辑器配置，体积大且每人不一样，不该上传。

### 5. 第一次提交

```powershell
git add .
git status
git commit -m "第 1-2 周：环境搭建 + Python 基础 5 个小程序"
git log --oneline
```

- `git add .`：把当前所有改动放进「待提交」区（暂存区）
- `git commit -m "..."`：拍一张快照，`-m` 后面是这次改动的说明
- `git log --oneline`：看历史快照，应该看到一行

### 6. GitHub 上新建空仓库

1. 浏览器打开 <https://github.com>，登录
2. 右上角 `+` → `New repository`
3. Repository name 填 **`ai-learning`**（英文，URL 会用到）
4. 选 **Public**（期末可以直接把链接给老师）
5. **不要**勾 "Add a README file"、**不要**选 .gitignore、**不要**选 license（本地已经有了，勾了会冲突）
6. 点 `Create repository`

### 7. 推上去

页面会显示一串命令，你只需要这三条（把 `<你的用户名>` 换成你的）：

```powershell
git remote add origin https://github.com/<你的用户名>/ai-learning.git
git branch -M main
git push -u origin main
```

`git push` 第一次会**弹出一个浏览器窗口**让你登录 GitHub 授权——**这是正常的**，登录并点同意，然后回终端等它推完。

看到类似这样就是成功了：

```text
branch 'main' set up to track 'origin/main'.
```

刷新 GitHub 仓库页面，应该能看到 `第01周-环境与第一行代码`、`第02周-Python基础` 这些文件夹。

## 注册 GitHub（如果还没有账号）

1. 打开 <https://github.com> → `Sign up`
2. 邮箱（常用邮箱，会收验证邮件）→ 密码 → 用户名（**英文/数字**，会出现在仓库链接里，比如 `yixin-ai`）

> 国内访问 GitHub 有时慢。别在早上上课前弄，晚上或午后人少的时候试。
> 打不开就先检查网络，别一上来就怀疑电脑。

## 卡住了怎么办

| 情况 | 先看 |
|---|---|
| `Please tell me who you are` | 第 2 步没配身份，回去配 |
| 弹浏览器登录 / 要 token | 正常，登录授权即可，**别去搜"密码"** |
| `failed to push some refs` | 远程仓库里已经有不属于本地的提交，先 `git pull --rebase origin main` |
| `not a git repository` | 终端不在 ai-learning 里，`cd` 回去 |
| 网络超时 | 重试；clone 用 `git clone --depth 1 <地址>` 只拉最新一次，快很多 |
