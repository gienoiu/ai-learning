## 小程序 1：打招呼（变量、input、f-string）

**目标**：学会「拿输入 → 存变量 → 打印」。

**要求**（存成 `作业提交/01_打招呼.py`）：

1. 用 `input()` 问「你叫什么名字？」，把回答存进变量 `name`
2. 打印：`你好，小明！`（换成输入的名字）
3. 再问「你今年几岁？」，把回答**转成整数**存进 `age`
4. 打印：`你今年 18 岁，明年 19 岁`

**输入 / 输出示例**：

```text
你叫什么名字？小明
你好，小明！
你今年几岁？18
你今年 18 岁，明年 19 岁
```

**验收标准**：输入「小明」「18」，输出包含 `你好，小明！` 和 `明年 19 岁`。

**提示**：
- `input()` 拿到的一定是**字符串**，要算数就得 `int(...)`
- 字符串拼接用 f-string：`f"你今年 {age} 岁"`

**自查三问**：`input()` 返回什么类型？为什么要 `int()`？f 字符串里的 `{}` 干什么？

## 小程序 2：温度换算表（for 循环、range、格式化）

**目标**：让循环替你重复干活。

**要求**（存成 `作业提交/02_温度换算.py`）：

打印 0℃ 到 100℃（每 10 度一行）对应的华氏度。公式：`F = C * 9 / 5 + 32`，**保留 1 位小数**。

**输出示例**：

```text
0℃  = 32.0℉
10℃ = 50.0℉
...
100℃ = 212.0℉
```

**验收标准**：一共 11 行；0 对应 32.0；100 对应 212.0；小数点后 1 位。

**提示**：
- `range(0, 101, 10)` 的第三个参数是「步长」
- f-string 里控制小数位：`f"{f:.1f}"`

**自查三问**：`range(0, 101, 10)` 为什么不包括 101？`:.1f` 是什么意思？

## 小程序 3：九九乘法表（嵌套循环）

**目标**：循环里套循环。

**要求**（存成 `作业提交/03_乘法表.py`）：

打印下三角的 9×9 乘法表，第 n 行有 n 个式子，同一行内用制表符 `\t` 隔开。

**输出示例**：

```text
1×1=1
1×2=2	2×2=4
1×3=3	2×3=6	3×3=9
...
```

**验收标准**：正好 9 行；第 n 行 n 个式子；最后一行到 `9×9=81`。

**提示**：
- 外层 `i` 从 1 到 9，内层 `j` 从 1 到 i
- `print(..., end="\t")` 可以让 print 不换行
- 内层循环结束后，单独来一个 `print()` 换行

**自查三问**：为什么内层是 `range(1, i + 1)`？`end="\t"` 改变了什么？那个 `print()` 是干嘛的？

## 小程序 4：词频统计（字典）

**目标**：第一次用字典解决真实问题。

**要求**（存成 `作业提交/04_词频统计.py`）：

给定文字（先写死）：

```python
text = "我爱学习，学习使我快乐"
```

1. 统计每个字出现了几次
2. 每个字打印一行：`字: 次数`
3. 再用循环找出出现次数最多的字，打印 `出现最多的是：X，共 N 次`

**输出示例**：

```text
我: 1
爱: 1
学: 2
习: 2
...
出现最多的是：学，共 2 次
```

**验收标准**：能正确统计；`学` 和 `习` 都是 2 次；出现最多的字能被找出来（并列时随便报一个都算对）。

**提示**：
- 字典计数：`d[字] = d.get(字, 0) + 1`
- 找最大值用循环：先假设第一个最大，再逐个比较
- 注意标点 `，` 也会被当成一个字，先不管它

**自查三问**：`get(字, 0)` 的 `0` 是干嘛的？为什么不直接 `d[字] += 1`？遍历字典用什么？

## 小程序 5：成绩单（列表 + 字典 + 函数）

**目标**：把前四周学的东西合起来，写一个「像程序」的东西。

**要求**（存成 `作业提交/05_成绩单.py`）：

初始数据：

```python
students = [
    {"name": "小王", "score": 85},
    {"name": "小李", "score": 92},
    {"name": "小张", "score": 78},
]
```

写三个函数：

1. `print_all(students)`：逐行打印 `小王: 85`
2. `average(students)`：返回平均分（保留 1 位小数）
3. `add_student(students, name, score)`：往列表里加一个学生

然后：加一个「小赵, 66」→ 打印全部 → 打印平均分 → 打印最高分的名字。

**验收标准**：运行后打印 4 行名单、平均分正确（80.3）、最高分是「小李」。

**提示**：
- 函数用 `def 名字(参数):` 定义，要返回结果就用 `return`
- 列表里的每个元素是一个字典，取名字用 `s["name"]`
- 算平均分：先求和再除以 `len(students)`

**自查三问**：`return` 和不写 `return` 有什么区别？为什么把列表传进函数，函数里改了外面也能看到？`len()` 干嘛的？
