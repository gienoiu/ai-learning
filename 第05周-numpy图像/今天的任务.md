# 第 5 周 · numpy 与图像

**清单原文**：numpy 图像是什么：数组、形状、索引、切片、广播；图片在计算机里就是一堆数字
**本周交付物**：用 numpy 手动实现图片的**变灰、翻转、裁剪**（清单第 7 项）

> 这周开始，你会第一次真正"看见"图片的本质：**一个数字矩阵**。
> 后面 CNN 做的一切（卷积、池化），都是在这些数字上算来算去。

## 第 4 步：三个任务

打开 `练习-图像处理.py`，里面有 3 个 TODO，按顺序做：

### 任务 A｜变灰（20 分钟）

把彩色图变成灰度图，公式（加权平均，人眼对绿色更敏感）：

```
灰度 = 0.299×R + 0.587×G + 0.114×B
```

要求：结果 shape 变成 `(240, 320)`（**少了一维**），保存成 `输出/变灰.png`。

### 任务 B｜翻转（20 分钟）

- 上下翻转 → `输出/上下翻转.png`
- 左右翻转 → `输出/左右翻转.png`

要求：只允许用 numpy 切片，不要用循环。

### 任务 C｜裁剪（20 分钟）

裁出图片中间偏右的一块（比如行 40~200、列 80~280），保存成 `输出/裁剪.png`。
要求：说出 `[40:200, 80:280]` 里哪一段是行、哪一段是列。

## 第 5 步：对照检查

用看图软件打开 `输出/` 里的 3 张图，和 `示例图片.png` 对比：

- 变灰：颜色没了，但四个色块的**明暗**不一样（红绿蓝的灰度值不同）
- 翻转：黄色圆跑到左上角，蓝色块跑到右边
- 裁剪：只看到一部分

## 第 6 步：回答这 5 个问题（发我，打字就行）

1. 一张图片在电脑里是什么？
2. `shape = (240, 320, 3)` 里三个数字分别是什么？
3. 为什么变灰之后变成 `(240, 320)`，少的那一维是什么？
4. 上下翻转为什么可以写成 `arr[::-1]`？
5. 切片 `arr[40:200, 80:280]` 里，`40:200` 和 `80:280` 分别对应图片的什么？
